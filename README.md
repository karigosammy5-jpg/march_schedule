# Production Data Tracking System (PMS)

## 📌 Project Overview
The Production Data Tracking System is a backend-focused application designed to bridge the gap between industrial operations and digital data management. Built with Django and PostgreSQL, this system allows for the logging, tracking, and analysis of production tasks in real-time.

I developed this project to solve the challenge of maintaining accurate records in high-velocity environments, drawing from my professional experience at Isuzu East Africa.

## 🚀 Tech Stack
* **Backend:** Python / Django
* **Database:** PostgreSQL
* **Frontend:** JavaScript / HTML / CSS
* **Version Control:** Git / GitHub

## 🛠️ Key Features & Logic
* **Relational Data Modeling:** Designed a robust PostgreSQL schema to handle relationships between production batches and individual tasks.
* **Dynamic Data Handling:** Implemented JavaScript-driven updates to allow for a seamless user experience without page refreshes.
* **Automated Status Tracking:** Built backend logic to automatically calculate production timelines and flag delays.

## 🧩 Technical Curiosity & Problem Solving
In line with the spirit of "building when no one is watching," I focused on solving the specific challenge of reading production schedules and keeping track of vehicles assembled in a day. This project reflects my transition from Automotive Engineering to Full-Stack Development, focusing on the rigorous logic required for industrial-grade software.
